> Repositório do projeto **Fullcycle Sonarcloud**.

## Tecnologias

- Python

## Como rodar

### Pré-requisitos

- Python 3.10+

### Instalação

```bash
git clone https://github.com/salomaocalheiros/fullcycle-sonarcloud.git
cd fullcycle-sonarcloud
pip install -r requirements.txt
```

### Execução

```bash
python main.py
```
